Got Questions? We’ve Got Answers

Do you store or look at my files?

Never. Every tool runs purely client-side via JavaScript inside your web browser. Your data never touches a remote server and stays completely on your hardware.

What’s the catch? Is it actually free?

No catch, no hidden paywalls, and no watermarks. Knullify is 100% free with unlimited usage—the only limit is the available RAM on your device.

How is the Image-to-Text conversion handled?

We leverage Tesseract.js, a robust open-source OCR engine operating entirely in-browser. It accurately reads text in English, Hindi, French, German, Spanish, and several other languages.

Which file formats can I upload?

Most tools natively accept PNG, JPG/JPEG, WebP, and BMP. Our PDF utilities handle both reading individual assets and compiling multi-page documents.

Is there support for batch-converting images to a single PDF?

Yes. You can select or drag-and-drop multiple images simultaneously into the Image → PDF engine, which will instantly merge them into a single, ordered document.

Can I use this on my phone?

Without a doubt. Knullify is built with modern web responsive standards, ensuring a flawless layout and fully operational tools on both iOS and Android browsers.
